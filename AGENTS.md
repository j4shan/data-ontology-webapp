# Webapp repository boundary

This project is the browser webapp and local application adapter. Consume the graph through its public JSON-RPC API; do not import graph internals. The adapter bridges browser HTTP requests to the graph-service Unix socket. External agents use the standard graph API directly; do not add a separate webapp SDK or CLI. The webapp owns committed, pre-built demo graph snapshots in `artifacts/catalogs/mcd/current` and `artifacts/catalogs/sbux/current`. Each directory contains independent copies of `nodes.json`, `edges.json`, and `annotations.json`, with no symlinks. Find them on GitHub at https://github.com/j4shan/data-ontology-webapp/tree/main/artifacts/catalogs. Use these bundled snapshots for demo startup; do not introduce runtime reads, links, scripts, or build paths into sibling repositories for these assets. Other catalogs, BI question assets, graph artifacts, AKG contracts, traces, and run results belong to the configurable Critic project. Keep secrets, dependency directories, browser builds, and temporary runtime output out of version control. Preserve the localhost-only initial deployment. Implement the stages serially and verify each before its delivery introduction.

The shared **Data catalog** dropdown selects McDonald’s or Starbucks in both tabs. The webapp loads the configured bundled snapshot through an installed `data-ontology-graph-server` executable, owns one graph process on a private temporary Unix socket, and stops that process on catalog change or shutdown. Do not manage unrelated graph daemons, consume sibling-project catalogs, or rebuild or republish YAML from browser requests. Production startup uses `DOG_GRAPH_SERVER` only to override the executable path; it does not consume `DOG_SOCKET`. Browser graph requests carry `catalog_id` and must be rejected if the selected catalog differs. Preserve generation checks that keep old catalog evidence out of the current view.

Do not create documents under `project_metadata/product/project_setting/`. The owner retired that documentation directory; do not recreate it or the deleted deployment document.
