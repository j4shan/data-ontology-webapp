# Webapp repository boundary

This project is the browser webapp and local application adapter. Consume the graph through its public JSON-RPC API; do not import graph internals. Catalogs, BI question assets, graph artifacts, AKG contracts, traces, and run results belong to the configurable Critic project. Keep secrets, dependency directories, browser builds, and runtime output out of version control. Preserve the localhost-only initial deployment. Implement the stages serially and verify each before its delivery introduction.

Do not create documents under `project_metadata/product/project_setting/`. The owner retired that documentation directory; do not recreate it or the deleted deployment document.
