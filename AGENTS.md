# Webapp repository boundary

This project is the browser webapp and local application adapter. Consume the graph through its public JSON-RPC API; do not import graph internals. The webapp owns committed, pre-built demo graph snapshots in `artifacts/catalogs/mcd/current` and `artifacts/catalogs/sbux/current`. Each directory contains independent copies of `nodes.json`, `edges.json`, and `annotations.json`, with no symlinks. Find them on GitHub at https://github.com/j4shan/data-ontology-webapp/tree/main/artifacts/catalogs. Use these bundled snapshots for demo startup; do not introduce runtime reads, links, scripts, or build paths into sibling repositories for these assets. Other catalogs, BI question assets, graph artifacts, AKG contracts, traces, and run results belong to the configurable Critic project. Keep secrets, dependency directories, browser builds, and temporary runtime output out of version control. Preserve the localhost-only initial deployment. Implement the stages serially and verify each before its delivery introduction.

Do not create documents under `project_metadata/product/project_setting/`. The owner retired that documentation directory; do not recreate it or the deleted deployment document.
